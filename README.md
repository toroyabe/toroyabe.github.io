# Zombie Survivors 殭屍倖存者

一款受《Vampire Survivors》啟發的自走射擊 / 倖存者類網頁小遊戲。
純 **HTML5 Canvas + 原生 JavaScript** 打造，**零外部相依**、開箱即玩，
手機與電腦皆可遊玩，可直接部署於 GitHub Pages。

🎮 **線上遊玩**：<https://deershop.me/>

## 玩法
- 角色自動朝最近的敵人開火，你只需專心走位躲屍潮。
- 擊殺殭屍掉落經驗寶石，集滿即升級 → 從三選一強化中挑選。
- 活得越久敵人越強、越多，挑戰你的存活時間與擊殺數紀錄。

## 操作
| 平台 | 移動 | 攻擊 |
|------|------|------|
| 電腦 | `WASD` / 方向鍵 | 自動 |
| 手機 | 左下角虛擬搖桿（觸控任意處） | 自動 |

`Esc` 或右上角按鈕可暫停。

## 系統設計重點（行為邏輯）
- **敵人 AI**：4 種殭屍各有行為 —— 步行者（基礎）、奔跑者（高速）、
  壯漢（高血量精英）、吐酸者（保持距離的遠程）。含群體分離避免疊在一起。
- **生成導演（Director）**：生成速率隨時間爬升，並週期性投放精英波。
- **武器系統**：手槍、霰彈槍、迴旋利刃、毒氣領域、雷射，各自獨立的
  冷卻、傷害、穿透與範圍成長曲線。
- **升級池**：武器升級 + 被動強化（傷害、攻速、移速、暴擊、磁力、再生…），
  以權重隨機抽取三選一。

## 開發 / 本機執行
不需建置工具，任意靜態伺服器即可：

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

## 檔案結構
```
index.html   介面與畫面（開始 / 升級 / 結束）
style.css    HUD、搖桿、卡片等樣式
game.js      遊戲核心：迴圈、AI、武器、升級、渲染
```
